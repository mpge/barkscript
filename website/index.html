Your code is barking.

The world's least serious programming language.

BarkScript is a real language written in dog commands. A lexer, a parser, a type checker and a compiler turn it into plain JavaScript you could ship. Whether you should is between you and your dog.

Fourteen commands. You already know most of them.

          

            Familiar dog commands, used for what they sound like. Strings, numbers, lists, objects and operators work
            the way they do in JavaScript, because underneath, that is what they are.

When something is wrong, Walter says so.

          

            The compiler checks the whole program before any of it runs, and every error has a line, a column, and
            usually the fix. These are produced live by the same compiler the playground uses.
          

        

        

      


      

        

          
Put it straight in your HTML.

          

            One script tag, then write BarkScript inside <script type="text/barkscript">. It compiles in
            the browser when the page loads. data-output also prints each woof into an element.

Install

          
Node.js 20 or newer. Then three steps.

        

        
    
          
  1. 
            
    Install the bark command
    
            
    npm install -g barkscript
    
          
    2. 
          
  2. 
            
    Write hello.bark
    
            
    woof "Hello, world!"
    
          
    3. 
          
  3. 
            
    Run it, or compile it to JavaScript
    
            
    bark run hello.bark
bark compile hello.bark   # writes hello.js
    
          
    4. 
        

        

          Editor support: a TextMate grammar and VS Code extension live in
          editors/vscode.
        

      


      

        

          
Teach Walter a new trick.

          

            BarkScript is MIT licensed and built in the open. The compiler is four small TypeScript files: lexer,
            parser, checker, code generator. Grammar changes start as an issue, so we can agree on the words first.
